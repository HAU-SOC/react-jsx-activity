# react-jsx-activity

Minimal template repository for testing pure JavaScript and React architectural knowledge using Node.js.

## Project structure

```text
react-jsx-activity/
├── src/
│   └── App.jsx
├── assignment.js
├── package.json
└── README.md
```

## Student instructions

1. Open `assignment.js` and complete all required functions.
2. Open `src/App.jsx` and replace or edit the React component based on your assignment/tutorial.
3. Export all required functions from `assignment.js` so the autograder can evaluate your work.
