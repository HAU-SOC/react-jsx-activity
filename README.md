# React JSX Activity Template

Use this repository as a starter template for React + JSX activities.

## What to customize

Update these items after creating your new repo from this template:

- **Project name**
- **Short project description**
- **Setup instructions**
- **Activity or assignment details**
- **Submission/checking instructions**

## Suggested structure

```text
.
├── src/
├── public/
├── package.json
└── README.md
```
